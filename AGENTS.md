## Commit messages

- Write a single-line commit message only — no multi-line body, no extra paragraphs or trailers.
- Prefix the message with a conventional commit type followed by a colon, e.g. `feat:`, `fix:`, `refactor:`, `chore:`, `docs:`, `style:`, `test:`, `perf:`.
- Example: `feat: add zen mode`
